## Changes against RC4

* Wait for the xtables lock (`-w`) in every helper `iptables`/`ip6tables` invocation. A concurrent
  lock holder (monitoring, an admin command, or the vendor engine) could make a read fail; the
  helper then failed closed and the restore path could not re-establish the removed dispatch,
  leaving the interface down until manual recovery. The commit now waits for the lock instead of
  aborting.
* Regression test pins that the helper passes `-w`; total off-device checks: 64 helper + 122
  firewall + 93 template + 70 mock = **349**.

RC3 and RC4 artifacts are unchanged and remain available for recovery
(`~/edgeos-vxlan-builds/rc3/`, `~/edgeos-vxlan-builds/rc4/`).
