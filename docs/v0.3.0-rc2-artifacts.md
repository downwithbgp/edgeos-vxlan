## What changed from RC1

RC2 is a targeted correctness and security review iteration; no new feature scope.

* Fail closed when the live firewall dispatch is ambiguous or unreadable, but only when an
  attachment is configured; an intentionally unfiltered interface is left unchanged.
* Configuration-API diagnostics are fatal instead of being read as "node absent".
* An unreadable administrative state is treated as "may be up"; a down is attempted and verified,
  and a down is never claimed when it failed.
* The interface is quiesced across a dispatch removal (the only transition that reduces
  enforcement) and reactivated only after the previous policy is restored and verified. The
  installed vendor binary was instrumented: a replacement/insertion is a single atomic
  `iptables --replace`/`--insert`, so only removals need quiescing.
* The gate verifies hook reachability from `INPUT`/`FORWARD` and a terminal default action in
  addition to the exact dispatch.
* A failed netdevice deletion after firewall mutation restores the pre-commit firewall and
  administrative state.
* The `vxlan41913` migration is a quiesced, fail-closed handover covering IPv4 `in`+`local` and IPv6
  `in`+`local`; rollback restores manual protection before detaching native enforcement or
  reactivating.
* The hardware runbook is classified by blast radius; global interventions are restricted to a
  disposable router.

## Supported installation procedure

**Platform:** Ubiquiti EdgeRouter X / ER-e50, EdgeOS 3.0.1 build 5862409,
Linux `4.14.54-UBNT`, MIPS little-endian. Do not install on another model, firmware or kernel.

1. Copy both `.deb` files to the router (for example with `scp`).
2. Verify the checksums on the router before installing:

   ```bash
   sha256sum \
     edgeos-vxlan-kmod_0.3.0~rc2+edgeos3.0.1.e50_mipsel.deb \
     edgeos-vxlan_0.3.0~rc2+edgeos3.0.1.e50_all.deb
   ```

   Expected:

   ```text
   5392e0b9069d51c2884bea0cde16e6a2b7abf9371d7bb8ab8e3ed01cbead76a3  edgeos-vxlan-kmod_0.3.0~rc2+edgeos3.0.1.e50_mipsel.deb
   6c922ac2ee0e67fefee7e4472c7c76473ffd34c472a6ffefe20df4662fd9ca1e  edgeos-vxlan_0.3.0~rc2+edgeos3.0.1.e50_all.deb
   ```

3. Install both packages in **one** `dpkg` transaction, kernel package first:

   ```bash
   sudo dpkg -i \
     edgeos-vxlan-kmod_0.3.0~rc2+edgeos3.0.1.e50_mipsel.deb \
     edgeos-vxlan_0.3.0~rc2+edgeos3.0.1.e50_all.deb
   ```

4. Verify:

   ```bash
   dpkg -l edgeos-vxlan edgeos-vxlan-kmod
   show configuration commands | grep -A8 'interfaces vxlan'
   sudo iptables-save -t filter | grep vxlan
   sudo ip6tables-save -t filter | grep vxlan
   ```

   Existing v0.2.2 configurations should be unchanged and existing VXLAN interfaces should not be
   recreated. The integration package depends on the stock `vyatta-cfg-firewall` and `iptables`
   packages, both present on the supported firmware.

5. The `install.sh` one-shot installer and the README install links remain pinned to the published
   **v0.2.2** release. They are not used for this RC. For the RC, use the explicit `dpkg -i` command
   above.
