## 2. Design constraints carried into implementation

* The firewall subtree declares **no priority**.
* The firewall leaves declare configuration and validation only; the reconciler applies the complete
  attachment set while it still holds the pre-change state.
* The reconciler and helper use the working-config `exists` API, not `existsEffective`: the latter
  reports the currently executing subtree as absent.
* The reconciler never writes configuration.
* The helper never flushes global tables, never creates policy, and only touches jumps matching the
  target interface.
* The parent gate runs before `ip link set up`; a failed gate leaves the interface down.
* Rollback restores the pre-commit firewall dispatch or leaves the interface down.
* Interface deletion removes the dispatch only after the netdevice is gone.
* Bridged VXLAN + firewall is rejected at validation.
* Existing configurations without firewall attachments are unchanged.

## 3. Verification gates

1. `bash test/run.sh` — static, unit, template and mocked reconciliation tests.
2. `shellcheck src/vyatta-vxlan src/vyatta-vxlan-bridge src/vyatta-vxlan-firewall test/*.sh`.
3. `dpkg-buildpackage -us -uc -b -a mipsel` and `./scripts/validate-release.sh`.
4. `bash test/integration-netns.sh` in a privileged Linux environment (root; generic netfilter
   semantics).
5. Optional emulated EdgeOS config-engine run with the official 3.0.1 firmware image.
6. Hardware acceptance per `docs/v0.3.0-hardware-acceptance.md` — required before tagging.

## 4. Deferred / out of scope

* Bridged L2 firewall enforcement.
* Per-interface `modify`/`ipv6-modify` (mangle) attachments.
* Automatic policy generation.
* Dynamic VTEP discovery, BGP EVPN, multipoint control planes, BFD, encryption.
* Source-address-dependent IPv6 routing (separate extension).
* Replacing the platform's iproute2 to fix the human-readable `ip -d` defect.
* Kernel changes or offload changes.

## 5. Open risks

| Risk | Mitigation | Evidence needed |
|---|---|---|
| Boot ordering installs attachments after the interface is up | Priority-less subtree + parent gate + continuous negative probe during boot | Hardware Phase 6 |
| Engine continues after a failed child action | Parent gate verifies effective attachments and takes the interface down | Hardware Phase 5 + emulated engine |
| Dispatch does not survive netdevice recreation | Iptables matches by name; gate re-verifies; recreation test | Hardware Phase 4 / netns test |
| Old ruleset deleted in the same commit as a recreation failure | Rollback restore fails; interface left down with explicit error | Hardware Phase 5 |
| `ubnt-fw` behavior differs on the real MIPS userland | Direct invocation on the router; existing native templates are the reference | Hardware Phase 2 |
| Package removal leaves live interfaces | `prerm` refuses while saved config or live VXLAN interfaces exist | Hardware Phase 8 |
