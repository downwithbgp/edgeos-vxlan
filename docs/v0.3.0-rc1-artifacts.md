## Supported installation procedure

**Platform:** Ubiquiti EdgeRouter X / ER-e50, EdgeOS 3.0.1 build 5862409,
Linux `4.14.54-UBNT`, MIPS little-endian. Do not install on another model, firmware or kernel.

1. Copy both `.deb` files to the router (for example with `scp`).
2. Verify the checksums on the router before installing:

   ```bash
   sha256sum \
     edgeos-vxlan-kmod_0.3.0~rc1+edgeos3.0.1.e50_mipsel.deb \
     edgeos-vxlan_0.3.0~rc1+edgeos3.0.1.e50_all.deb
   ```

   Expected:

   ```text
   3d6ca933f66a8a851d728f27b69e558ec4e8ad8df19f0808fdb429f20efd35fa  edgeos-vxlan-kmod_0.3.0~rc1+edgeos3.0.1.e50_mipsel.deb
   a3cd947de4ba73de0c414f3d91b73f00c7cb1549e26153c3e69288a4f4f9f013  edgeos-vxlan_0.3.0~rc1+edgeos3.0.1.e50_all.deb
   ```

3. Install both packages in **one** `dpkg` transaction, kernel package first:

   ```bash
   sudo dpkg -i \
     edgeos-vxlan-kmod_0.3.0~rc1+edgeos3.0.1.e50_mipsel.deb \
     edgeos-vxlan_0.3.0~rc1+edgeos3.0.1.e50_all.deb
   ```

4. Verify:

   ```bash
   dpkg -l edgeos-vxlan edgeos-vxlan-kmod
   show configuration commands | grep -A8 'interfaces vxlan'
   sudo iptables-save -t filter | grep vxlan
   sudo ip6tables-save -t filter | grep vxlan
   ```

   Existing v0.2.2 configurations should be unchanged and existing VXLAN interfaces should not be
   recreated. The integration package now depends on the stock `vyatta-cfg-firewall` and `iptables`
   packages, both present on the supported firmware.

5. The `install.sh` one-shot installer and the README install links remain pinned to the published
   **v0.2.2** release. They are not used for this RC. For the RC, use the explicit `dpkg -i` command
   above.
