## Changes against RC3

* Reject a ruleset chain that lost its configured rules: every configured rule number must be
  present in the effective chain (vendor `<chain>-<n>` comment format), in addition to the
  non-empty and terminal default-action checks. An unreadable rule list is a configuration-API
  failure, not an empty ruleset.
* Record the hardware-proven EdgeOS 3.0.1 scripted-commit firewall limitation and the support
  boundary (`docs/v0.3.0-edgeos-scripted-commit-limitation.md`,
  `docs/v0.3.0-support-boundary.md`).
* Regression: 64 helper + 121 firewall + 93 template + 70 mock = **348** off-device checks.

(`~/edgeos-vxlan-builds/rc3/`; v0.2.2 recovery packages are also staged).
